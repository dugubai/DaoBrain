## 范围与数量

本次实现固定、可复核的文化资料词法检索夹具，不生成随机文本，不导入真实档案、真实人名、个人资料、病历或秘密。语料文件位于 `common/corpus_fixtures.py`，不放在会被打包忽略的 `data` 目录。

| 分区 | 原有 | 新增 | 总数 | 分类 |
| --- | ---: | ---: | ---: | --- |
| GREEN | 4 | 18 | 22 | 核实典籍正文14条、明确模拟公开FAQ4条、明确模拟编辑规范4条 |
| RED | 2 | 10 | 12 | 全部为纯合成文化档案案例，来源类型为 `original` |
| UNKNOWN | 0 | 0 | 0 | 不取得默认公开语料 |

保留来源标识 `suwen-1/2/3`、`faq-0`、`synthetic-red-1/2`。公开模拟说明与典籍正文有不同标题和来源类型；规范使用已有枚举 `approved`，仅表示本地规范夹具类别，不表示实际授权审批通过。

`rag_public` 与 `rag_green` 共享同一个GREEN规范语料，`corpus_kb` 的公开检索与来源定位也使用它；`rag_red` 只检索RED夹具。这里没有独立向量库、向量嵌入、上传入库或真实训练模型。

## 按文化档案流程设计的模拟资料

以下流程是本项目模拟设计，不声称来自上述典籍、某机构真实规章或真实授权书。GREEN发布可展示的规则说明，RED保留尚待核验的工作形状；规则主题公开不意味着相关底稿可以公开。

| 环节 | 合成输入与状态 | 预期模拟处置 |
| --- | --- | --- |
| 采集授权 | 虚构节俗片段、范围表；展陈摘录允许，转写或再分发待核 | 形成待核清单，底稿本地保留，不扩大许可 |
| 编辑批注 | 虚构稿本批注建议把解释并入正文；状态待审 | 正文与批注分栏，不自动采用编辑建议 |
| 勘校异文 | 甲字与乙字占位符、定位一致、理由缺失 | 并列记录，补齐取舍理由前不得覆盖正文；占位符不是实际典籍异文 |
| 授权范围 | 虚构许可只含展陈，下载和转授不允许 | 逐用途核验，超范围导出不可放行 |
| 撤回申请 | 虚构撤回凭据待核、引用仍有使用方 | 先暂停引用，建立通知清单，记录核验与处置 |
| 版本冲突 | 初稿与复核稿定位不一致 | 形成差异清单，不因标签较新就覆盖旧证据 |
| 转写疑字 | 无真实扫描图，仅甲乙字符与疑字清单 | 保留原位待校，人工图文定位复核后才修改引文 |
| 展签编排 | 虚构展签把讲解放在引号里 | 分离讲解和原文，篇章待核前不发布 |
| 复核意见 | 引文通过、授权待补 | 分项保留状态，整体暂停发布，不合并成通过 |
| 衍生撤回 | 虚构底稿与展签、问答的引用链 | 暂停衍生展示并记录处置，保留核验依据 |

全部RED正文都含 `纯合成演示` 和 `无真实用户秘密` 标记。甲、乙等是占位对象，不是联系人、个人身份或真实保密内容；不存在实际采集录音、病历或授权书附件。客户端批准、检索命中、来源哈希都不能代替独立人工复核，也不能实现红转绿。

## 安全与证据边界

- 保留 `catalog._entry` 构造和 `sha256(text + "\n" + VERSION)`，`VERSION` 仍为 `simulation-v1`。哈希针对整理后的夹具正文，而非外部网页或扫描文件。正文修正改变哈希，旧正文即使沿用来源标识也不可信。
- `trusted` 对照完整规范记录，文本、区标签、来源标识、标题、定位、引用、来源类型、版本、哈希任一篡改均拒绝；重算伪造文本或伪造版本的哈希也不建立可信性。
- `catalog` 返回深拷贝，调用方修改不会污染后续检索。UNKNOWN为空，不取得GREEN；任何一条RED不得从公开来源定位接口获取。
- 只新增逐条声明的GREEN主题，不新增宽泛未知词通行规则。`public_query` 的未知残词拒绝、敏感词、数字、URL及NFKC归一化屏蔽保持不变；主题加无关词仍拒绝。RED主题不进入公开列表。
- 词法评分仍为关键词与双字重叠，无单字命中、无空结果回退。RED检索不是敏感性分类器；区隔离和推理端证据校验不能由查询主题替代。
- `extract` 保留最多4条、调用方输出长度限制与免责声明，不拆截引文。`supported_quotes` 仍核验精确引文、文本、唯一来源与实际使用的证据集合，拒绝自创解释、伪造引文及未使用证据。
- `tests/test_local_modules.py` 的 `request_payload` 仅取前4条，不再把全库送进最多20条的 `InferRequest`；正式模型与请求契约上限不修改。

```bash

```

新增测试覆盖每条排名、全部关键词与主题、核实正文清单、逐字段篡改、伪造摘要/版本、UNKNOWN空、跨区推理拒绝、所有公开检索入口一致、公开来源版本/哈希定位拒绝、敏感词与数字URL屏蔽、未知残词与无关词不回退、最多4条及精确长度边界、完整引文验证。

最终执行结果：911项通过，耗时2.68秒；无失败。两条警告分别来自Starlette对AnyIO旧别名的使用，以及原有篡改测试把枚举改为字符串后触发的Pydantic序列化提示；本次未修改相关依赖或放松测试。

语料扩充前的 `common/catalog.py` 和 `tests/test_local_modules.py` 已备份到源码目录之外的独立工作区。公开仓库不包含备份、真实用户资料或模型权重；服务器源码安装也逐文件独立备份，不永久删除文件。
